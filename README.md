# Defense Training Template

Reusable proposal template for a CCW and firearms-training business.

## Role In The Business

- This repo is a proposal asset, not a core maintained production client surface.
- It helps show how CSolutions can package a regulated-service offer into a strong landing-page build.
- Keep it in the mockup lane unless it is explicitly promoted to active client work.

## Shared Docs

- `CLAUDE.md`
- `AI-WORKFLOW.md`
- `SECURITY-CHECKLIST.md`

## Stack

- Next.js 15 App Router
- React 19
- Tailwind CSS 4
- TypeScript

## Local Development

```bash
npm install
npm run dev
```

Useful build commands:

```bash
npm run build
npm run start
npm run lint
```

## Main Editing Surfaces

- `src/app/` for route structure
- `src/components/` for landing-page sections
- `src/data/site.ts` for placeholder brand info, course pricing, and contact details
- `public/images/` for approved client visuals after the template is customized

## Working Rules

- Keep copy and offer framing clean and direct.
- Treat this as a reusable proposal build, not a permanent business hub.
- Keep all placeholder contact details and media generic until the next prospect is approved.

## Security Notes

Run `SECURITY-CHECKLIST.md` before demos or deploys. The main risks are stale contact details, copied proposal data, and any third-party form or analytics wiring.
